===== what the spec itself asserts about the condition (§4) =====
The a11y spec's 17th arm asks the harness's OWN Express (through Vite's proxy, via the
'request' fixture, which page.route does not intercept) and asserts the invariant that ties
the two readings together: the server's rows are exactly the corpus files at the path it
reports. With the empty dir: 0 files -> 0 rows + 1 skip. With the clone: 322 -> 322 + 0.
So the suite is proven under BOTH conditions, and a runner's condition is one of them.
