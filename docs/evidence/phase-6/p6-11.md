## ac2 — the missing-only filter, and the numbers as text

`?missing_only=1` is a **server-side SQL predicate** (`has_definition = 0`); `1`/`true` on, `0`/`false`/absent off, anything else a **`400`** (`Invalid missing_only "yes": expected 1/0 (or true/false).`). The tier-1 arm drives it and sees **1717 → 1395 rows, equal to the view's `missing`**, recording the request URL; the query builder is unit-tested (16 tests) with the parameter name in one shared home. **D85**: `defined`/`missing` render as **text** with the glyph `aria-hidden`, and the header/percentage/row count are all text. The executor also had to swap two text tokens for measured ones because the repo's contrast test refuses an unmeasured token — recorded rather than silenced.
