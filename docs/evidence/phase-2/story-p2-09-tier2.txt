## 7. Corpus scale, measured (prompted by the owner's note that the wiki lists ~1,539 side + ~2,325
##     storyline quests — far more than the 322 in this repo)
The local corpus is exactly the repo's own files: 322 x QuestTemplates/*.json, 9.6 MB.
GET /api/quests, three consecutive runs: 0.536s / 0.452s / 0.446s, 71,328 bytes each — it scans the
directory and JSON5-parses every file PER REQUEST (D12), joined with entry_status.
NOTHING hardcodes the count: grep for "322" in client/src + server/src finds only comments describing
measured corpus facts plus one doc-comment quoting the spec's example string; the summary, the tab badges
and the "Showing 1-50 of N" string are all derived from the scan. So a bigger corpus changes the numbers
automatically — but the measured cost is the thing to watch: ~3,900 quests (~12x) would make this endpoint
roughly 12x slower and 12x larger (~860 KB, several seconds), so D12's "322 files is fine locally"
assumption now has a measured boundary and wants a caching decision before the corpus grows. Recorded as
D52(i); the browse page holds no client-side cap either (50 rows per page, but the whole list is fetched).
