## 4. maxBuffer escape hatch, exercised for REAL
   The big capture's stdout is 55,177,495 bytes (measured in the ac2 evidence),
   i.e. above the spec's 50 MB cap — so the service must retry with --output.
$ curl -s --max-time 180 -o /tmp/p204-evidence/ac3-big-resp.json -w 'HTTP %{http_code}  %{size_download} bytes  %{time_total}s' -F "file=@/tmp/p204-evidence/big-capture.json" http://localhost:3139/api/extract/quests
  HTTP 200  38514036 bytes downloaded  28.335332s
  curl exit=0   wall=28.34s

$ node -e '<count the quests in the API response>'
  top-level keys: quests, count
  count: 3200 | quests.length: 3200
  first/last quest name: MB-YARD1-C01-001 / MB-YARD1-C01-001

  The >50 MB stdout was impossible to buffer, so the response can only come from
  the --output retry. The service announces that on stderr:
$ grep 'extract' /tmp/p204-evidence/ac3-server.log
