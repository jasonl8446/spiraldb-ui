## 3. A flake the LEAD's gate run exposed, and its honest fix
The first lead gate run failed ONE UI test — the committed p2-07 assertion 'the { } toggle opens
exactly 400px of syntax-highlighted JSON' (`expect(box?.width).toBe(400)`) — while the executor's
own full-suite run had passed it. It passed twice in isolation. Diagnosis: the panel SLIDES IN, so
an immediate `boundingBox()` can land mid-transition; the assertion races the CSS transition, and
the Wrap container p3-10 added made the transition window wide enough to lose the race under load.
The assertion itself is right (spec L326 really does say 400px), so it was NOT relaxed: it is now
polled — `await expect.poll(async () => (await panel.boundingBox())?.width).toBe(400)` (the repo's
established timing pattern, p3-04/p3-06).
```
$ npx playwright test tests/ui/quests-detail.spec.ts -g "exactly 400px"   # x3
  1 passed (3.1s) / 1 passed (3.0s) / 1 passed (2.9s)
$ npm run test:ui
  170 passed (38.9s)      # the full suite under load, flake gone
```
