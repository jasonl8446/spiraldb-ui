## How the post-pass joins (never by position)

`tools/PacketReaderCli/ObservedFields.cs` runs after `QuestBuilder` returns and after the D46 level repair.

- **Quest -> QuestID**: the first `MSG_SENDQUEST` whose `QuestTitle` equals the quest's `m_questTitle`, the same
  rule as `QuestBuilder.AddQuestIDToQuestTemplate` (QuestBuilder.cs:105-114). `MSG_QUESTOFFER` (no `QuestID`)
  joins through that title map. `MSG_COMPLETEQUEST` joins by `QuestID`.
- **GoalID -> extracted goal**: QuestBuilder keeps its GoalID map private, so the post-pass replays its identity
  rule (QuestBuilder.cs:123-128). It walks the quest's `MSG_SENDGOAL`s in capture order. The first `GoalID` to
  carry a `GoalNameID` owns the extracted goal with that `m_goalNameID`, including a compilation goal re-sent by
  packet. A later `GoalID` with an owned `GoalNameID` is the duplicate the reader skipped, so its values are
  reported as "the reader dropped this goal". `MSG_COMPLETEGOAL` and `MSG_PERSONAINFO` join by `GoalID`.
- **Decodes**: a string; a UBYT flag that is 0/1 -> boolean; a `uint`; `ActivityType` byte -> `ACTIVITY_*`
  through Imcodec's generated `ActivityType` enum (`Enum.IsDefined`); `ClientTags` hex -> `ClientTagList` via
  `ObjectSerializer.Deserialize<ClientTagList>(bytes, 1)`, the call QuestBuilder uses for goal tags. Anything
  else is reported, not written. Conflicting observations of one field are reported, not written. An empty
  string or empty tag list is neither written nor reported.
- **Reports**: one JSON line per value on stderr:
  `{"report":"observed-field","quest","path","source","value","reason"}`.

What was recovered: every planted quest-level value (`m_questNameID`, `m_questInfo`, `m_noQuestHelper`,

Planted values that are **reported by design, not written**:
- `MSG_SENDQUEST.PetOnlyQuest` (5): the quest schema has no `m_petOnlyQuest`.
- `MSG_COMPLETEQUEST.CompleteText` (5): `m_questComplete` is a string-table key. Imlight never fills this packet
  field (`QuestService.SendCompleteQuest` sets only `QuestID`), so nothing shows the two hold the same kind of
  value. This follows the spec's rule for that field.
- `PersonaName` planted on a non-persona goal (5: Waypoint x2, Scavenge, Bounty, AchieveRank). Only
  `PersonaGoalTemplate` has `m_personaName`, in both Imcodec and the zod schema.
- **Measured limit, story 7.4:** in `WC-TUT-C05-001`, the values planted on ACHIEVERANK goals 1-4 (4 PersonaName +
  4 CompleteText). The reader keeps 1 of the 5 goals (`1_`, `GoalNameID 0`) and drops the other 4 as duplicates,
  so those 8 values have no goal to land on. They are reported with the owning GoalID. Goal 0's CompleteText is
  written to `1_`. This criterion is met for every goal the reader produces; the 4 dropped goals come back only
  when 7.4 repairs the naming.

## Field-diff script (p7-field-diff.mjs)

```js
// p7-04 evidence: field-level diff of each p7 wrapper output against its inject spec. For every planted
// observed value: WRITTEN (value at its path, compared exactly), REPORTED (no home; a stderr report line
// with the same path/source/value), or DIFF. Goals are joined GoalID -> GoalNameID -> m_goalNameID (the
// first GoalID to carry a GoalNameID owns that goal), never by position. Ids are parsed as bigints.
import { spawnSync } from 'node:child_process';
import fs from 'node:fs';
import path from 'node:path';
const DIR = 'server/test/fixtures/captures/p7';
const ACTIVITY = ['ACTIVITY_NotActivity', 'ACTIVITY_Spell', 'ACTIVITY_Crafting', 'ACTIVITY_Fishing', 'ACTIVITY_Gardening', 'ACTIVITY_Pet'];
const PERSONA = 'Imcodec.ObjectProperty.TypeCache.PersonaGoalTemplate, Imcodec.ObjectProperty';
const exact = (_k, v, c) => (typeof v === 'number' && !Number.isSafeInteger(v) ? BigInt(c.source) : v);
const env = { ...process.env, DOTNET_ROOT: path.dirname(fs.realpathSync(spawnSync('bash', ['-c', 'command -v dotnet'], { encoding: 'utf8' }).stdout.trim())) };
let total = 0, diffs = 0;
for (const quest of fs.readdirSync(DIR).filter((f) => f.endsWith('.inject.json')).map((f) => f.slice(0, -12)).sort()) {
  const spec = JSON.parse(fs.readFileSync(`${DIR}/${quest}.inject.json`, 'utf8'));
  const capture = JSON.parse(fs.readFileSync(`${DIR}/${quest}.json`, 'utf8'), exact);
  const run = spawnSync('tools/bin/imview-packet-reader', ['--input', `${DIR}/${quest}.json`], { env, encoding: 'utf8' });
  const out = JSON.parse(run.stdout)[0];
  const reports = run.stderr.split('\n').filter((l) => l.startsWith('{"report"')).map((l) => JSON.parse(l));
  const f = (e, n) => e.data.fields[n]?.value;
  const rows = [];
  const check = (label, p, source, want, got, homeless) => {
    const rep = reports.filter((r) => r.path === p && r.source === source && JSON.stringify(r.value) === JSON.stringify(want));
    const ok = homeless ? rep.length > 0 : JSON.stringify(got) === JSON.stringify(want) && rep.length === 0;
    rows.push(`${ok ? 'ok  ' : 'DIFF'} ${homeless ? 'REPORTED' : 'WRITTEN '} ${label.padEnd(44)} ${p} = ${JSON.stringify(homeless ? want : got)}${homeless ? `  (${rep[0]?.reason})` : ''}`);
    total++; if (!ok) diffs++;
  };
  const map = { QuestNameID: ['m_questNameID', (v) => v], QuestInfo: ['m_questInfo', (v) => v], NoQuestHelper: ['m_noQuestHelper', (v) => v === 1], SkipQHAutoSelect: ['m_skipQHAutoSelect', (v) => v === 1], ActivityType: ['m_activityType', (v) => ACTIVITY[v]], ClientTags: ['m_clientTags', (v) => v.tags] };
  for (const [k, v] of Object.entries(spec.sendQuestFields)) {
    if (k === 'Rewards') continue; // inferred (task 7.5)
    if (k === 'PetOnlyQuest') { check(`MSG_SENDQUEST.${k}`, 'm_petOnlyQuest', `MSG_SENDQUEST.${k}`, v, undefined, true); continue; }
    check(`MSG_SENDQUEST.${k}`, map[k][0], `MSG_SENDQUEST.${k}`, map[k][1](v), out[map[k][0]], false);
  }
  const qid = f(capture.find((e) => e.data.name === 'MSG_SENDQUEST'), 'QuestID');
  const owner = new Map();
  for (const e of capture) if (e.data.name === 'MSG_SENDGOAL' && f(e, 'QuestID') === qid && !owner.has(f(e, 'GoalNameID'))) owner.set(f(e, 'GoalNameID'), f(e, 'GoalID'));
  const goalFor = (gid) => { const n = f(capture.find((e) => e.data.name === 'MSG_SENDGOAL' && f(e, 'GoalID') === gid), 'GoalNameID'); const g = owner.get(n) === gid ? out.m_goals.find((x) => x.m_goalNameID === n) : undefined; return [g, g ? `m_goals[${g.m_goalName}]` : `m_goals[GoalID ${gid}]`]; };
  let at = 0;
  for (const step of spec.sequence) {
    while (capture[at].data.name !== step.message) at++;
    const env0 = capture[at++];
    for (const [k, v] of Object.entries(step.fields ?? {})) {
      const source = `${step.message}.${k}`, label = `${source} (goal ${step.goal ?? '-'})`;
      if (step.message === 'MSG_COMPLETEQUEST') { check(label, 'm_questComplete', source, v, undefined, true); continue; }
      const key = { PersonaName: 'm_personaName', CompleteText: 'm_completeText', GoalHyperlink: 'm_hyperlink' }[k];
      const [g, gp] = goalFor(f(env0, 'GoalID'));
      check(label, `${gp}.${key}`, source, v, g?.[key], !g || (key === 'm_personaName' && g.$type !== PERSONA));
    }
  }
  for (const e of capture.filter((x) => x.data.name === 'MSG_SENDGOAL' && f(x, 'QuestID') === qid)) {
    const [g, gp] = goalFor(f(e, 'GoalID'));
    if (g) for (const [k, key] of [['NoQuestHelper', 'm_noQuestHelper'], ['PetOnlyQuest', 'm_petOnlyQuest']]) check(`MSG_SENDGOAL.${k} (GoalID ${f(e, 'GoalID')})`.slice(0, 44), `${gp}.${key}`, `MSG_SENDGOAL.${k}`, f(e, k) === 1, g[key], false);
  }
  const unexplained = reports.filter((r) => !rows.some((row) => row.includes('REPORTED') && row.includes(` ${r.path} = `)));
  console.log(`\n=== ${quest}  (exit ${run.status}; ${rows.length} planted/observed values; ${reports.length} report line(s); unexplained reports: ${unexplained.length})`);
  for (const r of rows) console.log(`  ${r}`);
  diffs += unexplained.length;
}
console.log(`\nfield-level diff: ${diffs} over ${total} value(s)`);
process.exit(diffs === 0 ? 0 : 1);
```
